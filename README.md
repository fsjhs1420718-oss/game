## 📖 開發緣由與動機

在數位遊戲普及的時代，絕大多數的卡牌與解謎遊戲高度依賴「文字敘述」來傳達規則與世界觀，這對**學齡前兒童、不識字族群或跨語言使用者**構成了無形的遊玩門檻。

本專案的誕生旨在打破文字的藩籬：
* **無障礙設計（Accessibility First）**：以高辨識度的色彩、大型符號（Emoji）與向量圖示（FontAwesome）取代所有操作說明與故事文本，實現真正的「看圖就能玩」。
* **成就感與正向回饋**：結合「記憶翻牌」的專注力訓練與「開寶箱抽卡」的驚喜感，並透過視覺粒子特效與集卡相簿，提供無需音效干擾的純粹視覺成就感。
* **輕量化與零依賴**：採用單一 HTML 檔案架構（Single-File Architecture），無需安裝龐大的遊戲引擎或後端伺服器，開啟瀏覽器即可隨時隨地遊玩。

## ✨ 核心特色

| 特色維度 | 設計亮點說明 |
| :--- | :--- |
| 🚫✍️ **100% 以圖代文** | 遊戲介面完全摒棄文字按鈕，全數採用直覺的圖示（🧩 遊戲、🎁 寶箱、🖼️ 圖鑑、👁️ 提示、🔄 重置）進行互動。 |
| 👑✨ **三階稀有度與特效** | 內建 24 種跨文化故事主題（希臘神話、童話、魔法、龍族、太空等），劃分為 **⚪ 普通**、**🟣 稀有**、**👑 金色傳說**，搭配專屬脈衝光芒與粒子煙火特效。 |
| 🔄🗝️ **雙核心無縫循環** | 透過「翻牌配對」賺取鑰匙（🗝️），消耗鑰匙開啟寶箱解鎖新卡牌；當鑰匙耗盡時，系統會透過視覺動態提示**自動跳轉**回翻牌關卡，確保遊玩體驗不中斷。 |
| 🎨🌸 **馬卡龍溫馨視覺** | 採用明亮柔和的馬卡龍淺色系（粉紅、奶油黃、天空藍）搭配現代俐落的**思源黑體（Noto Sans TC）**，打造親切無壓力的展覽級一頁式網頁平台。 |
| 🔍🤫 **隱藏探索彩蛋** | 開發者在鍵盤事件中埋藏了神秘的「兩位數快捷指令」，觸發後可體驗一鍵破關與滿屏金色粒子爆發的驚喜！ |

## 🎮 遊戲玩法與操作指南

1. **🧩 記憶翻牌（賺取鑰匙）**：
   * 點擊蓋住的寶石卡牌將其翻開，找出兩張相同圖示的卡牌進行配對消除。
   * 遇到困難時，可點擊頂部的 **👁️（偷看按鈕）** 獲得短暫的全場透視提示。
   * 全部配對成功通關後，即可獲得 **🗝️ +3 鑰匙** 獎勵！
2. **🎁 寶箱抽卡（解鎖圖鑑）**：
   * 切換至寶箱頁面，消耗 `1` 把鑰匙點擊跳動的神秘禮盒，即可隨機抽取一張故事卡牌。
   * 若鑰匙用盡，畫面將自動跳出動態引導並返回翻牌模式。
3. **🖼️ 集卡冊相簿（成就展示）**：
   * 隨時點擊相簿圖示檢視收集進度，未解鎖的卡牌會以 `🔒` 剪影呈現，集滿全套 24 張將點亮專屬獎盃 `🏆`！

## 🛠️ 開發迭代歷程

本專案經歷了五個階段的持續優化與體驗打磨：

* **Phase 1｜概念確立與無字化設計**
  * 确立「不識字也能無障礙遊玩」的核心目標，捨棄複雜圖片與文字，建立以高對比色彩與大型 Emoji 為主的 20+ 種故事卡牌庫。
* **Phase 2｜核心玩法與獎勵機制整合**
  * 結合「翻牌記憶」與「盲盒抽獎」雙重機制，設計三級稀有度視覺反饋，並決定捨棄語音與音效，專注於純粹且絢麗的 3D 翻牌與粒子特效。
* **Phase 3｜防呆引導與隱藏彩蛋實作**
  * 加入「無鑰匙自動跳轉」的流暢體驗設計；同時在不破壞介面簡潔度的前提下，實作鍵盤隱藏破關彩蛋。
* **Phase 4｜一頁式展覽平台包裝**
  * 將獨立遊戲核心嵌入一頁式介紹網站中，整合專案特色、時間軸與彩蛋線索提示，實現「開啟網頁即刻試玩」的展示效果。
* **Phase 5｜色彩心理學與字體微調**
  * 將初版的深色夜空風格全面重構為明亮溫暖的**馬卡龍淺色系**；字體歷經多次調整，最終定案為現代且極具易讀性的**思源黑體（Noto Sans TC）**。

## 🚀 快速開始

本專案為純前端單一檔案架構，無需任何建置工具（Build Tools）或伺服器環境：

1. **複製專案或下載檔案**
   ```bash
   git clone https://github.com/your-username/visual-story-card-game.git
   ```
2. **啟動遊戲**
   * 直接雙擊目錄下的 `index.html` 檔案，使用任一現代瀏覽器（Chrome, Edge, Safari, Firefox）開啟即可立即遊玩！
