# game
階段一：核心需求確認（無文字與純視覺定位）
初始目標：希望製作一款單一 HTML 檔案的簡易卡牌遊戲，牌面需包含 20 種以上代表不同故事主題（如古希臘、神話、競技、童話、魔力等）的圖示。

無障礙設計：考量到不識字的使用需求，確立了「完全以圖代文」的核心原則，避免過多圖片與文字說明，全部改以高辨識度的色彩與大型符號、Emoji 呈現。

階段二：遊戲玩法與獎勵機制確立
透過問答釐清偏好後，決定了遊戲的互動與成就感來源：

雙核心循環：結合「翻牌記憶配對」（過關賺取鑰匙）與「寶箱盲盒抽獎」（消耗鑰匙抽取卡牌）。

分級與收集：卡牌劃分為普通、稀有與金色傳說三種稀有度，抽到的卡牌會自動收錄進「集卡冊相簿」中供隨時欣賞。

視聽取向：捨棄音效與語音朗讀，將重點完全放在絢麗的視覺特效（如 3D 翻牌動畫、發光邊框、滿屏煙火粒子）。

階段三：體驗優化與隱藏彩蛋設計
流暢度優化：新增「當鑰匙耗盡時，點擊寶箱會自動跳轉回翻牌遊戲」的無縫引導機制。

隱藏彩蛋：在不改動原有遊戲邏輯與版面的前提下，於背景加入了隱藏的鍵盤監聽事件（連續輸入特定數字即可觸發自動破關、獲得無限鑰匙並解鎖全圖鑑），且畫面上不顯示任何明示按鈕。

階段四：升級為一頁式展覽網站
整合展示：將原本獨立的遊戲檔案嵌入為一頁式介紹網站的核心平台，讓使用者打開網頁即可直接預覽與遊玩。

內容擴充：在網頁中加入了「遊戲亮點特色」、「開發歷程時間軸」以及「隱藏要素提示區」（暗示玩家嘗試按數字鍵探索彩蛋，但保密具體數字）。

階段五：視覺配色與字體微調
色彩轉換：針對初版網頁偏暗的風格進行調整，將全站與遊戲介面改為明亮、溫暖且具親和力的馬卡龍淺色系。

字體定案：經歷了從預設字體調整為典雅的「標楷體」，最終定案為現代、俐落且易讀性極高的「思源黑體（Noto Sans TC）」，完成最終版本的網站定稿。
